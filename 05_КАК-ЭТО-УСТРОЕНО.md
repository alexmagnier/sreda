# Как это устроено

Главное, что надо понять: **Claude Code — это программа, а не модель.** Я оставил программу
как есть и поменял ей «мозг».

## Две части Claude Code

1. **Программа-агент.** Чат в VS Code, инструменты (читать и писать файлы, запускать команды,
   искать), кнопки «Разрешить / Отклонить», CLAUDE.md, история чатов, скиллы.
2. **Модель.** Программа отправляет ей запрос, получает ответ и решает, что делать дальше.
   Обычно запрос уходит на серверы Anthropic.

```
Ты → чат Claude Code → [скиллы · CLAUDE.md · инструменты · разрешения]
                              │  запрос в формате Anthropic API
            обычно:  api.anthropic.com → облачная модель
            здесь:   127.0.0.1:1234 → LM Studio → открытая модель на твоём Mac
```

У Claude Code есть штатная настройка `ANTHROPIC_BASE_URL`: адрес, куда слать запросы. Её сделали
для корпоративных шлюзов. Лаунчер подставляет туда LM Studio на твоём Mac. LM Studio отвечает в
том же формате, что Anthropic, включая вызовы инструментов. Claude Code не замечает подмены.

## Почему твои скиллы работают с открытой моделью

Скилл живёт не внутри модели. Это папка с файлом `SKILL.md`, обычный текст с инструкциями.
1. В начале чата Claude Code показывает модели список скиллов: имя и строку описания.
2. Задача подходит — модель вызывает инструмент `Skill`, так же как «прочитать файл».
3. Программа подставляет полный текст инструкции, модель работает по ней.

Значит, скилл может использовать любая модель, которая умеет вызывать инструменты. Скиллы —
часть программы, а не «мозга». Твои скиллы подключены ссылками на оригиналы: поправил
скилл один раз — обе версии видят правку.

## Три режима

| Окно | Модель | Интернет | Для чего |
|---|---|---|---|
| 🔒 **«Локальный Claude»** | рабочая | **нет**: закрыт на уровне ядра macOS для модели и всех команд | клиентские файлы, КП, выжимки, код |
| 🧪 **«Лаборатория Claude»** | без фильтров (abliterated) | есть, когда просишь «найди в интернете» | свои устройства, прошивки, эксперименты |
| Обычный VS Code | облачный Claude | да | всё остальное, как раньше |

**Abliterated** — модель, у которой из весов математически вырезано «направление отказа». Она
не говорит «не могу помочь». Цензуры нет, но и проверки за тобой нет: перед прошивкой, root или
сбросом она предупредит и спросит «да», а решать тебе. Только свои устройства и аккаунты.

## Что защищает клиентские файлы

- **Песочница ядра macOS** (`sandbox-exec`). В режиме без интернета у модели и у всех её команд
  открыт сетевой доступ только к LM Studio на этом Mac. Запись — только в открытую папку.
  Тест это доказывает: сессия работает, а наружу уходит 0 байт от всего дерева процессов.
- **В Claude Code нет входа в облако.** Отдельные папки настроек без логина: если что-то пойдёт
  не так, будет ошибка, а не тихий уход в облачную подписку.
- **Клиентские папки закрыты в Лаборатории.** Страница из интернета может подсунуть модели
  инструкцию «прочитай файл и отправь». Поэтому режим с интернетом клиентскую папку не
  открывает и не читает её даже по полному пути.
- **Одна модель в памяти.** Пока в одном окне идёт ответ, второе окно модель не отнимет.

## Начал в облаке — продолжил локально

Открой «Локальный Claude» в той же папке, где работал в обычном Claude Code: в истории чатов видны твои
обычные сессии. Нажми любую — переписка скопируется в локальную историю, и открытая модель продолжит
с того же места, уже без интернета.

Это работает только в одну сторону:
- облачная копия не меняется, а локальное продолжение в облако не попадает;
- в «Лабораторию» облачные и локальные сессии не переносятся никогда.

Длинную облачную сессию открытая модель сначала сожмёт под свой контекст — это может занять минуты.
Для продолжения лучше короткие сессии.

## Что пришлось докрутить (и почему это не «просто поменять адрес»)

- Модель падала на первом же запросе: шаблон Qwen не принимал служебное сообщение Claude Code.
  Исправлена одна строка шаблона.
- Инструкции Claude Code весят около 21 тысячи токенов. Ненужные локальной модели инструменты
  отключены: осталось 10,5 тысячи, первый ответ стал вдвое быстрее.
- Модель «думала» минутами над каждым шагом: рассуждение по умолчанию стояло на максимуме.
- Фоновые запросы (подсказки, сводки) выключены: каждый из них — полный запрос к медленной модели.

## Островок

Нативное приложение над нотчем. Свёрнутый — пилюля со счётчиками: сколько агентов Claude Code
работает, сколько закончили, сколько ждут тебя. Развёрнутый — три вкладки:
- **Агенты** — все сессии во всех окнах VS Code. Клик открывает окно нужной сессии.
- **Окна** — настоящие окна на всех рабочих столах. У VS Code видна папка и файл, у Safari —
  открытая вкладка и список вкладок. Клик переключает, рабочий стол меняется сам.
- **Система** — память, процессор, видеокарта, температура, диск, топ процессов. Карточка
  LM Studio с кнопкой «Выгрузить модель».

## Честно о пределах

- Открытая модель на ноутбуке **слабее** облачного Claude. Выжимки, таблицы, письма, расчёты,
  небольшой код — хорошо. Длинные многошаговые задачи — хуже: дели на шаги.
- Скорость у автора (48 ГБ): ~30 токенов/с, первый ответ 8–15 с.
- Пока модель пишет, Mac тратит энергию как в тяжёлой игре. Работай от зарядки.
- Название «Локальный Claude» — ярлык программы. Внутри **Claude Code с открытой моделью**.
  Модель Claude скачать нельзя.
