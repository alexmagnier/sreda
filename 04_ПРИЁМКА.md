## Что НЕ обещаем

- Локальная модель слабее облачного Claude: длинные многошаговые задачи и тонкая аналитика —
  хуже. Задачи дели на шаги.
- Без поиска модель уверенно выдумывает коды, порты и версии. Для устройств — всегда «найди в интернете».
- Связка «Claude Code + не-Claude модель» официально не поддерживается Anthropic. После обновлений
  Claude Code — прогон тестов (раздел B).
- Режим без интернета закрывает передачу данных с компьютера. Юридическую оценку обработки
  персональных данных он не заменяет.
