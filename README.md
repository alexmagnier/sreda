# СРЕДА — открытая модель в Claude Code, модель без цензуры и островок над нотчем

Ты закидываешь эту папку в Claude Code. Твой Claude сам проверяет код, подбирает модели под твой
Mac, ставит, тестирует и в конце даёт тебе инструкцию. Получаешь то же, что работает у меня:

1. **«Локальный Claude».** Тот же чат Claude Code в VS Code, с твоими скиллами, но модель
   крутится на твоём Mac. Интернет закрыт на уровне ядра macOS, поэтому клиентские файлы
   никуда не уходят.
2. **«Лаборатория Claude».** Модель без цензуры с поиском в интернете — для своих устройств,
   прошивок и экспериментов.
3. **Островок над нотчем.** Какие агенты работают, какие закончили, какие ждут тебя. Окна на
   всех рабочих столах (какая папка в VS Code, какие вкладки в Safari), память, процессор,
   кнопка «выгрузить модель».

## Что нужно

- Mac на Apple Silicon (M1 и новее). Intel и Windows — нет.
- Память от 16 ГБ. Нормально работает от 32 ГБ, у меня 48 ГБ.
- 80 ГБ свободного места: модели большие.
- VS Code с расширением Claude Code и подписка Claude: установку делает твой обычный Claude.
- Островок — macOS 26. На более старой системе Claude предложит адаптацию, но я её не проверял.
- 1,5–3 часа, большая часть — загрузка моделей. Mac на зарядке.

## Как запустить

1. Скачай папку: на GitHub — зелёная кнопка **Code → Download ZIP**, распакуй. Положи куда угодно,
   хоть в Загрузки: Claude сам скопирует код в `~/local-ai`.
2. VS Code → **Файл → Открыть папку** → эта папка → открой Claude Code.
3. Вставь промпт:

```
Это пакет СРЕДА. Прочитай CLAUDE.md в этой папке и установи всё по 01_ПЛАН-УСТАНОВКИ.md.
Начни с фаз 0 и 1: проверь код пакета и мой Mac, задай вопросы одним списком и покажи план.
Без моего «да» ничего не устанавливай.
```

Дальше Claude будет звать тебя несколько раз:
- ответить на вопросы: где у тебя клиентские папки, какие скиллы подключить;
- ввести пароль, если нужно поставить Homebrew (команду он даст, выполняешь сам);
- нажать «Установить» для инструментов разработчика Apple;
- открыть готовые окна и включить островку разрешение «Универсальный доступ».

## Честно, до установки

- Открытая модель на ноутбуке **слабее** облачного Claude. Выжимки, таблицы, письма, расчёты,
  небольшой код — хорошо. Длинные многошаговые задачи — хуже, их надо делить на шаги.
- Скорость у меня: ~30 токенов в секунду, первый ответ 8–15 секунд.
- Пока модель пишет, Mac тратит энергию как в тяжёлой игре. Работай от зарядки.
- Модель без цензуры не отказывает, но и не страхует. Только свои устройства и аккаунты,
  ответственность за применение на тебе.
- «Локальный Claude» — название программы. Внутри Claude Code с открытой моделью: саму модель
  Claude скачать нельзя.
- Связку «Claude Code + чужая модель» Anthropic официально не поддерживает. После обновления
  Claude Code попроси своего Claude прогнать тесты. Как — написано в инструкции, которую он тебе оставит.
